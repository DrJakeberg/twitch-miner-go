# Code of Conduct

## Our Pledge

We as members, contributors, and maintainers of this project pledge to make participation in our community a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, color, religion, or sexual identity and orientation.

We pledge to act and interact in ways that contribute to an open, welcoming, diverse, inclusive, and healthy community.

## Our Standards

Examples of behavior that contributes to a positive environment:

- **Being respectful** — differing opinions and experiences are valid; disagreements are technical, not personal
- **Giving and accepting constructive feedback gracefully** — criticism is aimed at code, not people
- **Focusing on what is best for the community** — consider how your actions affect the project and its users
- **Showing empathy** — contributors come from different backgrounds, time zones, and skill levels

Examples of unacceptable behavior:

- **Harassment** — sexualized language or imagery, unwelcome advances, deliberate intimidation, stalking, or following
- **Trolling, insulting, or derogatory comments** — personal or political attacks, dismissive or gatekeeping language
- **Publishing others' private information** — without explicit permission (real names, contact details, physical addresses)
- **Other conduct which could reasonably be considered inappropriate** in a professional setting

## Scope

This Code of Conduct applies to all project spaces — including issues, pull requests, discussions, the wiki, and any other communication channel associated with this repository — as well as public spaces where an individual is representing the project (e.g., social media, conferences, or online events).

## Reporting

If you experience or witness unacceptable behavior, report it privately to the maintainer. All reports will be reviewed and investigated promptly, fairly, and with discretion.

**[Open a GitHub Security Advisory](https://github.com/Guliveer/twitch-miner-go/security/advisories/new)** — select "I'd like to report a security vulnerability" and indicate in the description that this is a Code of Conduct report. This creates a private channel visible only to the repository maintainer.

Alternatively, contact the project maintainer directly via a private communication channel if one is established.

**To report an issue involving the maintainer**, please use the same Security Advisory process — the advisory system is accessible to multiple repository owners if applicable, ensuring independent review.

Your report will be handled with confidentiality. You will not be required to confront anyone, and retaliation of any kind is not tolerated.

## Enforcement

When a violation is reported, the maintainer will:

1. **Acknowledge receipt** within 72 hours
2. **Gather context** — review the reported behavior and relevant history
3. **Determine a response** from the following options, depending on severity and context:

### Corrective Action Guide

| Violation | Response |
|---|---|
| Unintended minor violation (e.g., a one-off inappropriate comment) | Private warning explaining what was inappropriate and what change is expected |
| Repeated minor violations or a single moderate violation | Public warning on the channel where the violation occurred, with a clear explanation of the unacceptable behavior |
| Significant violation (e.g., harassment, publishing private info) | Temporary suspension from all project spaces |
| Severe or persistent violation | Permanent ban |

The maintainer's goal is to resolve the situation and restore a safe environment — not to punish. Warnings and decisions will be communicated clearly to both the reporter and the subject of the report.
